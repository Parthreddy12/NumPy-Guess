# NumPy Guess Number Game 🎯

NumPy Guess Number Game is an interactive Python console-based game where the **computer intelligently guesses the number chosen by the user (between 1 and 100)**.

Instead of random guessing, the program uses a **Binary Search algorithm** to reduce the search range by half after each response, allowing the computer to find the correct number efficiently in very few attempts.

## Features

* User thinks of a number between **1–100**
* Computer asks smart questions based on the current range
* Uses **binary search logic** for efficient guessing
* Quickly narrows down the possible number
* Simple and interactive terminal-based gameplay

## Algorithm Used

This project is based on **Binary Search**, a highly efficient searching algorithm.

How it works:

1. Start with a range from **1 to 100**
2. Find the middle number
3. Ask the user whether their number is greater than the middle
4. Reduce the search space based on user input
5. Repeat until the correct number is found

This reduces the number of guesses significantly compared to random guessing.
